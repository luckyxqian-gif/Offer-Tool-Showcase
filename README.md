# Offer Tool Showcase

**[打开可交互网页版](https://luckyxqian-gif.github.io/Offer-Tool-Showcase/)**

这是 Offer Tool 的面试展示仓库，只保留面试官实际需要访问的公开内容：

- `site/`：已验证的静态网页版，以虚构岗位、公司和流程数据展示主要能力；操作仅保留在当前浏览器标签页，并可恢复初始演示数据。
- `.codex/skills/resume-tailor-cn/`：原定公开的通用简历修订 Skill 快照，不含候选人事实、私人策略、私人简历底版或个人化样例。
- `site/legal/`：网页版实际包含的第三方前端库许可。

网页版不连接真实飞书、模型、Codex、搜索服务、本地文件或其他外部系统。任务 Prompt 会要求执行端读取当前环境中最新安装、当前有效的对应 Skill；行业研究、自我表达、模拟面试、真实面试复盘等其他 Skill 均未上传或固化在本仓库。

本仓库不包含桌面端、后端、本地部署代码、构建与测试过程、修改记录、数据库、日志、凭证、真实飞书数据或私人资料。

## English

This interview showcase contains only the deployed static demo, the previously approved public `resume-tailor-cn` snapshot, and the licenses required by the web bundle. The demo uses fictional data, stores changes only in the current browser tab, and does not connect to real external services. Desktop, backend, local-deployment, build-process, personal-data, credential, and change-history materials are not included.
