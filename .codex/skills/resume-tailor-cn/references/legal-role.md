# 法律专业增量

本 Reference 只在目标岗位或 selected evidence 需要法律专业判断时读取。它只补充法律对象、法律关系、争点、合同、程序、法律判断、法律交付、法律术语和法律场景中的特殊事实层级；不决定某段法律经历能否向银行、合规、政策、风险或其他目标转化。该转换统一由 Business Mapping 决定。

## 法律工作链

在真实材料中识别：

- 法律对象：合同、交易、案件、监管规则、证据、程序、业务流程；
- 法律关系与主体边界；
- 争点、规则效力、责任边界、赔偿范围、证据缺口或程序选择；
- 法律 Action 与 Judgment：检索、比较、论证、审查、起草、修改、尽调、谈判、程序推进；
- 法律 Deliverable：法律意见、合同修改稿、答辩/代理材料、研究报告、清单、底稿、程序文件；
- 真实 Result、Stage Result 和 downstream use。

这些层级用于准确理解事实，不是固定 taxonomy，不要求每条 bullet 全部具备。

## 特殊事实层级

法律工作函数、法律问题、Action、材料对象、Deliverable / Result 不是天然同级。材料、局部争点、程序动作或案件类型不能仅因具体、醒目、数量多或有完整 STAR 就自动成为 `work_classification`。

反之，原始场景是诉讼也不自动锁定“争议解决”。当事实真实包含规则适用、平台审核异常、数据边界、未成年人保护、合同风险或其他合规主题时，可交给 Business Mapping 判断目标导向主轴；只有普通诉讼程序动作时不得虚构合规职责。

## 法律术语与表达增量

事实与 Writing 应优先使用成熟准确的法律对象、法律关系、案由、合同/交易结构、程序、法律文书和交付名称。允许不改变含义的简历化缩写；不得为高级感把“准备申请、检索类案、核对材料”改成“设计路径、构建机制、建立体系”。

法律正文优先让真实法律 Action + 法律对象 + Judgment / Deliverable 可见；沟通协调只有在确实说明责任、程序推进或结果时保留。具体 W1–W6、颗粒度和 Relation Check 仍由 `resume-writing.md` 唯一负责。

## 研究、陌生行业与边界

研究经历保持研究身份，特殊边界见 `research-experience-mapping.md`。陌生行业可建议用户未来完成真实研究后补位，但未完成的报告、项目或经历不能先写入简历。

本文件不保存个人事实，不生成面试题或行业报告，不维护独立 semantic gate、匹配等级、选材算法或写作流程。
