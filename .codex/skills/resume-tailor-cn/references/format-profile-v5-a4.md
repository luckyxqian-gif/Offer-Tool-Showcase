# v5 A4 Format Profile

## 来源与适用范围

母版来源是用户确认的 v5 Word。源文件实际为 Letter；最终 HTML 固定为 A4。转换只映射页面几何，不重新设计字体、层级、照片、标题、横向结构或整体风格。当前默认字体规范由经人工确认的 Profile 固化。

首版 Profile 的来源 SHA-256 为 `5decc43481909d3b486c0fdec7346f4c4e9928c91adf79728f3f9f95d0adb6ea`。不得将源 DOCX、照片或正文复制进 Skill。

机器可读参数位于 `../assets/format-profile-v5-a4.json`。HTML 母版位于 `../assets/resume-v5-a4.html`。

## 模板证据

- Word 页面：21.59 × 27.94 cm，左右边距 1.30 cm，上 1.60 cm，下 1.50 cm。
- 全局默认文字（包括姓名、联系方式、教育普通字段和 bullet 正文）：`Songti SC, STSong, SimSun, 宋体, serif`。
- 大标题与每条经历的完整标题行（单位/项目名称、中间字段、日期）：`Microsoft YaHei, 微软雅黑, sans-serif`。
- 姓名：18 pt，加粗。
- 正文：10.5 pt，13.5 pt exact。
- 大标题：12.5 pt，加粗，`#2E54A1`，13 pt exact。
- 大标题段前、段后有效值约 6.5 pt。
- 公司或项目标题：10.5 pt，加粗，13.5 pt exact，段前 0.6 pt、段后 0.4 pt。
- bullet：左缩进 0.688 cm，悬挂 0.370 cm；Word 中是字面量 `• `。
- 公司或项目中间字段中心：源内容区宽度的约 56.08%；日期位于内容区右边界。
- 教育表：无边框、零内边距、固定四列，总宽约占源内容区 94.62%。
- 照片：2.25 × 3.00 cm，3:4；源 Word 使用不稳定的浮动锚点。

## HTML 映射

- 页面改为 210 × 297 mm，边距保持 13 / 13 / 16 / 15 mm。
- 法律实践与科研成果的中间字段均使用 `research-middle-anchor`，即内容区 62.50% 的共同中心锚点；两个板块的日期都贴 A4 内容区右边界。
- 教育网格保留四列比例并扩展至内容区全宽，使日期与其他栏目共享最右基准；不依赖 Word 表格或手工空格。
- 照片使用页面内容区内固定区域，保持 2.25 × 3.00 cm；默认横向位置按源模板比例映射，允许在首次视觉校准时做极小调整。
- 蓝色横线用 CSS 的“标题粗下划线 + 右侧连续线”实现，不复制 Word 的尾随空格；两段线共享底部基线，绝不能穿过标题字面中线。

## 可校准与不可校准

首版校准已使用 v5 的真实内容和照片在 Codex 内置浏览器完成。正文、标题层级、横向锚点和页面几何与 v5 的结构证据一致；标题类间距的初始估计经真实页面占用复核后无需改值。`v5-a4-7` 保留标题下划线的垂直基线，并取消标题与右侧横线之间的断口；法律实践和科研成果共用略偏右的固定中间锚点，教育网格扩展至内容区全宽，使所有日期共享最右基准。浏览器对 CSS 毫米换算存在小于 0.75 mm 的像素舍入，QA 使用固定容差识别 A4，不把舍入误报为页面尺寸错误。

本次校准允许并核验的变量只有：

- 公司或项目标题行段前、段后；
- 四个大标题段前、段后；
- 照片区域的极小坐标偏移；
- Letter 到 A4 后的横向比例映射误差。

Profile 版本、默认值及安全上下限已经锁定。以后不得针对每份简历自由重算；只有更换母版或经用户明确确认重新校准时才能发布新的 Profile 版本。

正文 10.5 pt、正文与 bullet 13.5 pt 行距、bullet 缩进、A4 页边距和横向标题锚点是硬参数，不参与自动适配或视觉填充。
